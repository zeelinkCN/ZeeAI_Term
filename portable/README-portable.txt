ZeeAI Terminal 0.1.14 - 便携版 / Portable
=========================================

怎么用 / How to run
-------------------
1. 双击 ZeeAI_Term.exe 即可，无需安装。
2. 左侧「远程」→ 点「＋ 新建会话」（或直接在「已保存的服务器」里点服务器）。
   连接时会问要不要用 tmux：可以新建一个 tmux 会话，也可以附加到已有的。
3. 同一个弹窗里可以改「登录用户」：想用普通用户登录就把 root 改成你的用户名，
   远程文件和 tmux 都会跟着这个用户走（勾上「保存到配置」下次默认用它）。
4. 侧栏「文件」子标签可以浏览服务器目录，点文件即可看 Markdown / HTML 预览（默认渲染效果）。
   工具栏有「上传 / 新建文件夹」；每个文件行尾的 ⋯（或直接右键）可以下载、重命名、删除。
5. 服务器要新建 / 编辑 / 复制 / 删除：点「已保存的服务器」旁边的 ⋯，或顶部菜单
   「连接 → 服务器管理…」。
6. 左侧还有 PowerShell / CMD / WSL / Git / 串口 / ADB 等本地工具；顶部菜单、底部齿轮都能用。
   串口面板不再罗列系统里所有 COM 口：点「＋ 新建串口连接」，选端口和波特率（还能设数据位/
   停止位/校验/流控）保存后才会出现在列表里，每条连接各用各的参数。
7. Git 图标里可以「＋ 打开本地仓库」：选一个本地仓库目录，直接在那个目录开一个本地终端
   （PowerShell/CMD/WSL 按设置走），可以直接敲 git 命令；这个工作空间会存下来，下次点一下就能用。
8. 文件面板工具栏的「✓ 跟随终端」默认开启：点「刷新」会跳到终端（tmux）当前所在目录。
9. 会话标签可以右键「重命名会话…」，名字会记进会话历史。
10. 文件面板多了「⤓ 同步终端目录」：你在终端里 cd 到哪，点一下就跟过去
    （tmux 会话和普通 shell 都支持）。远端文件走真正的 SFTP（不是 scp）。
11. Git 面板现在能干活：新建仓库 / 暂存 / 取消暂存 / 丢弃改动 / 提交 / 看提交历史和 diff /
    分支切换与新建；工作空间里点「新终端」可以在该仓库目录再开一个终端。
12. 左侧 PowerShell / CMD / WSL 模块会列出**已经打开的会话**，点一下就能切过去，不用去顶部找标签。
13. 会话列表里服务器默认展开：单击服务器名展开/收起它的会话历史，双击或右键打开服务器设置。
14. 密码登录的服务器：在「编辑服务器」里把密码存进 Windows 凭据管理器（不会写进配置文件），
    之后远程文件、tmux 列表都能用（不存密码的话，终端仍会自己弹提示让你输入）。
15. 退出时自动保存工作区，下次打开恢复上次的会话（SSH / 本地终端 / 串口）；
    设置里可以关掉。
16. 传输有进度条了：右下角会显示每个文件的百分比和进度。
17. 跳板机：编辑服务器时填「跳板机」（写法同 ssh -J，例如 user@跳板机的地址:22），
    终端和文件管理都会自动走跳板。
18. 分屏：「视图」菜单里可以选左右/上下两分屏、三分屏、四分屏；
    点左侧会话就放进当前聚焦的窗格，同一页面能同时看好几台机器。
19. 右侧 AI 面板**本版暂停用**：点最左侧图标栏底部的星星按钮只会打开一块灰色空容器，
    面板里的内容（看板 / 卡片 / 刷新 / 时间线）一律不渲染，也不显示红点数字。
    代码和设计原样保留，等后续重构；想恢复要两步：把源码里 AI_PANEL_DISABLED
    （src/lib/ai-labels.ts）改成 false，再把设置 JSON 里的 aiWatchEnabled 打开——
    它默认关，本机日志与 herdr 状态的后台监视不启动。
    看板那份「看本机 codex 日志 + herdr 状态、不自动探测」的口径随之暂停。
20. 命令面板：Ctrl+Shift+P。
21. 断点续传：传一半的文件再次上传/下载会自动从断点接着传。
22. 终端日志：右键会话标签可以「开始记录终端日志」，输出会存成纯文本
    （已去掉颜色控制符，记事本可直接看），默认放在
    %APPDATA%\ZeeAI-Terminal\logs\sessions\；正在记录时标签上有红点。
    设置里可以开「新建会话自动记录」。
23. 终端回滚行数可调：设置里 1k / 10k / 50k / 200k 一键切换（默认 1 万行）。
    满了是丢掉最老的行（不会崩），要长期留存就开第 22 条的日志。
24. tmux / vim 里拖不出选区：按住 **Shift 拖拽**即可强制本地选择（xterm 原生支持）；
    也可以右键终端 →「选择/复制模式」（快捷键 Ctrl+Shift+Space），进入后拖选，
    有「选中即复制」就自动复制，Esc 退出；退出时只恢复进入前真的开着的鼠标上报。
25. 会话标签前的 T / H / S 徽标：蓝 T = tmux、绿 H = herdr、黄 S = 纯 SSH
    （本地终端不加徽标）。悬停能看到这个会话到底跑在哪。
26. 「✍ 发给 AI」输入窗按会话独立：每个会话有自己的草稿和附件，切走再回来还在；
    发送只清当前会话，关会话才清掉那一格。
27. 连接诊断：编辑服务器里点「连接诊断」，连接失败提示里也能点进去。它只读本机配置
    （跑一次 ssh -G，**不连服务器**），显示实际生效的主机 / 端口 / 用户 / 跳板机，
    以及每个候选密钥是否存在（✓ / ✗），并给一句人话结论。
28. 主机密钥（TOFU）：第一次连某台服务器会记下它的指纹（known_hosts.json），
    以后指纹变了会**拒绝连接**并提示删掉对应条目——这是防中间人的，不是故障。

依赖 / Requirements
-------------------
- Windows 10/11（需要系统自带 WebView2 Runtime，Win11 默认已有）
- SSH 使用系统自带 OpenSSH 客户端，密钥沿用你 ~/.ssh 里的配置

关于 ADB
--------
本便携版已内置 platform-tools（resources\platform-tools\）。
第一次点「刷新设备」时 Windows 可能弹防火墙授权——这是 adb 的正常行为，允许即可。

配置文件 / Config
-----------------
%APPDATA%\ZeeAI-Terminal\
  profiles.json     连接配置
  history.json      会话历史
  settings.json     设置
  known_hosts.json  SSH 主机密钥指纹（TOFU；换密钥后要删对应条目）

注意 / Notes
------------
- 不要单独把 exe 拷走：resources 目录要和 exe 放在一起（ADB 依赖它）。
- 卸载 = 删除整个文件夹，再手动删掉上面的 %APPDATA% 目录。
- 这一版（0.1.14）是"SSH 问题集中修 + 输出链路提速 + 安全补洞"，用法基本不变：
  · SSH 报错全部收口成「中文分类｜原始信息：英文」，不再出现孤立的「 - 」；
    新增「连接诊断」（编辑服务器 / 连接失败提示两处入口），只读 ssh -G 看实际生效的
    主机/端口/用户/密钥/跳板机；密码模式会提示"本机已有免密配置，密码模式不用
    ~/.ssh/config 与 ssh-agent"；
  · 「发给 AI」输入框改成**每个会话各自一份**草稿与附件（以前切标签会串）；
  · tmux 里拖选复制：Shift+拖拽强制本地选择 + 右键「选择/复制模式」兜底；
  · AI 面板暂停用（点开只有灰色空容器，内容不渲染，代码保留待重构）；
  · 会话标签加 T / H / S 徽标（tmux / herdr / 纯 SSH，本地不加）；
  · 安全：新增主机密钥 TOFU（换密钥会拒连）、配置与历史改原子写（坏文件先备份
    成 .bad-时间戳，不再静默重置）、ADB 命令与「打开外部链接」的注入面收掉；
  · 输出链路：PTY 输出 16ms / 64KB 合并、带 seq 确认的真背压、会话日志 64MB 轮转，
    300k 行大输出实测 IPC 次数 -95.5%、WebView2 峰值内存 -28%。
  改动全清单与已知限制见仓库 docs/release-notes-v0.1.14.md。
