ZeeAI Terminal 0.1.0 - 便携版 / Portable
=========================================

怎么用 / How to run
-------------------
1. 双击 zeeai-terminal.exe 即可，无需安装。
2. 左侧「远程」→ 点「＋ 新建会话」（或直接在「已保存的服务器」里点服务器）。
   连接时会问要不要用 tmux：可以新建一个 tmux 会话，也可以附加到已有的。
3. 同一个弹窗里可以改「登录用户」：想用普通用户登录就把 root 改成你的用户名，
   远程文件和 tmux 都会跟着这个用户走（勾上「保存到配置」下次默认用它）。
4. 侧栏「文件」子标签可以浏览服务器目录，点文件即可看 Markdown / HTML 预览（默认渲染效果）。
   工具栏有「上传 / 新建文件夹」；每个文件行尾的 ⋯（或直接右键）可以下载、重命名、删除。
5. 服务器要新建 / 编辑 / 复制 / 删除：点「已保存的服务器」旁边的 ⋯，或顶部菜单
   「连接 → 服务器管理…」。
6. 左侧还有 PowerShell / CMD / WSL / Git / 串口 / ADB 等本地工具；顶部菜单、底部齿轮都能用。
   串口面板不再罗列系统里所有 COM 口：点「＋ 新建串口连接」，选端口和波特率（还能设数据位/
   停止位/校验/流控）保存后才会出现在列表里，每条连接各用各的参数。
7. Git 图标里可以「＋ 打开本地仓库」：选一个本地仓库目录，直接在那个目录开一个本地终端
   （PowerShell/CMD/WSL 按设置走），可以直接敲 git 命令；这个工作空间会存下来，下次点一下就能用。
8. 文件面板工具栏的「✓ 跟随终端」默认开启：点「刷新」会跳到终端（tmux）当前所在目录。
9. 会话标签可以右键「重命名会话…」，名字会记进会话历史。
10. 文件面板多了「⤓ 同步终端目录」：你在终端里 cd 到哪，点一下就跟过去
    （tmux 会话和普通 shell 都支持）。远端文件走真正的 SFTP（不是 scp）。
11. Git 面板现在能干活：新建仓库 / 暂存 / 取消暂存 / 丢弃改动 / 提交 / 看提交历史和 diff /
    分支切换与新建；工作空间里点「新终端」可以在该仓库目录再开一个终端。
12. 左侧 PowerShell / CMD / WSL 模块会列出**已经打开的会话**，点一下就能切过去，不用去顶部找标签。
13. 会话列表里服务器默认展开：单击服务器名展开/收起它的会话历史，双击或右键打开服务器设置。

依赖 / Requirements
-------------------
- Windows 10/11（需要系统自带 WebView2 Runtime，Win11 默认已有）
- SSH 使用系统自带 OpenSSH 客户端，密钥沿用你 ~/.ssh 里的配置

关于 ADB
--------
本便携版已内置 platform-tools（resources\platform-tools\）。
第一次点「刷新设备」时 Windows 可能弹防火墙授权——这是 adb 的正常行为，允许即可。

配置文件 / Config
-----------------
%APPDATA%\ZeeAI-Terminal\
  profiles.json   连接配置
  history.json    会话历史
  settings.json   设置

注意 / Notes
------------
- 不要单独把 exe 拷走：resources 目录要和 exe 放在一起（ADB 依赖它）。
- 卸载 = 删除整个文件夹，再手动删掉上面的 %APPDATA% 目录。
