# ZeeAI_Term v0.1.4

这一版两个交互上的改进：**侧栏折叠更顺手**，以及给 tmux 用户一套**可点的按钮**。

## 这一版改了什么

### 1. 左侧图标：点一下就折叠 / 展开侧栏

以前想藏掉侧栏，得去顶部「视图 → 隐藏侧栏」，用起来别扭。现在按 VS Code 的习惯：

- **点当前这个图标** → 侧栏**折叠**；
- **点另一个图标** → 切到那个模块，并把侧栏**展开**；
- 侧栏收着的时候再点一次同一个图标 → 又展开。

「视图」菜单里那一项保留（改叫「折叠侧栏 / 展开侧栏」），命令面板 `Ctrl+Shift+P` 里也能搜到。

### 2. 新面板：tmux 快捷操作（不用再背 Ctrl+B 了）

连上 tmux 会话后，**左侧边栏底部**会出现一个「tmux 快捷操作」面板（只有 tmux 会话才显示，可折叠）：

| 分类 | 按钮 | 等价快捷键 |
|---|---|---|
| 窗口 | 新建窗口 / 上个窗口 / 下个窗口 / 关闭窗口 | `Ctrl+B c` / `p` / `n` / `&` |
| 分屏 | 左右分屏 / 上下分屏 | `Ctrl+B %` / `"` |
| 窗格 | 窗格 ← ↑ ↓ → / 放大·还原 / 换布局 / 关闭窗格 | `Ctrl+B 方向键` / `z` / `空格` / `x` |
| 查看 | 滚动查看 / 退出滚动 | `Ctrl+B [` / `q` |
| 其它 | 重命名窗口 / **脱离会话** | `Ctrl+B ,` / `d` |

鼠标停在按钮上会显示它等价于哪个快捷键 —— 用着用着就记住了。

面板里还列出**当前会话的所有窗口**（编号、名字、几个窗格、哪个是当前），**点一下直接切过去**，
省得按 `Ctrl+B 0/1/2` 数数。列表每 10 秒自动对一次表（面板收起就不打扰服务器），也能点 ↻ 手动刷新。

**重点：`Ctrl+B` 一点没动。** 我们没有去改 tmux 的前缀键，也没有模拟按键 ——
面板是**另开一条 ssh 直接跑 tmux 命令**。所以：

- `Ctrl+B` 在终端里照旧原样可用，你的手感不变；
- 就算当前窗格在跑 vim / python 这种占着键盘的程序，按钮照样管用。

安全上也收了口子：前端只能传“动作名”，后端用白名单映射成具体 tmux 命令，
不接受前端拼命令；会话名做引号转义，窗口编号只认数字。

### 3. 体积

主程序 15.22 MB → **15.30 MB**（+80 KB），**没有新增任何第三方依赖**。

## 升级方式

- 已经在 **0.1.3**：设置 → 检查更新 → **一键升级到 0.1.4 并重启**，点一下就行；
- 还在 0.1.2 或更早：需要**手动装一次**本版（之后就能一键升了）。

配置存在 `%APPDATA%\ZeeAI-Terminal\`，升级不会丢。

## 已知限制

- 仅 Windows；未做代码签名（首次运行 SmartScreen 会提示"未知发布者"）
- 一键升级依赖系统自带的 `curl.exe`（Win10 1803+ 内置）；下载速度取决于你到 GitHub 的线路
- tmux 面板是 tmux 2.x 以上的通用命令，没测过非常老的 tmux（1.x）
- 非 bash 的远端 shell 拿不到实时工作目录（tmux 会话不受影响）
