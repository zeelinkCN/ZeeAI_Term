# ZeeAI_Term v0.1.1

修掉三条让人不爽的界面问题，另外把"自动化脚本会抢串口"这个隐患从根上解决了。
**已经装了 0.1.0 的话，打开应用 → 设置 → 检查更新，就能看到这一版。**

## 下载

| 文件 | 说明 |
|---|---|
| `ZeeAI_Term_0.1.1_x64-setup.exe` | **推荐**：NSIS 安装包，双击装 |
| `ZeeAI_Term_0.1.1_x64_en-US.msi` | MSI 安装包（适合企业批量部署） |
| `ZeeAI_Term-0.1.1-portable.zip` | 便携版：解压双击即用，含内置 ADB |
| `ZeeAI_Term.exe` | 单文件免安装版（建议直接用便携版 zip） |

## 这一版改了什么

### 1. 窗口中间不再弹任何东西

以前出错会蹦一个红色浮层，正好压在终端上。现在**浮层代码整块删掉了**，
所有提示只出现在**底部状态栏**，按严重程度分三档：

| 级别 | 样子 | 停留 |
|---|---|---|
| 完成（已上传 / 已删除 / AI 跑完…） | `✓` 半透明白底 | 8 秒 |
| 提醒（还没好、已重试 5 次…） | `⚠` 琥珀黄底 | 8 秒 |
| 出错（失败 / 无法 / 请先…） | `❗` 红底 + 加粗 + 闪三下 | 12 秒 |

点一下可以立刻关掉。

### 2. 右键菜单不再是浏览器的

以前在终端里右键会看到「刷新」「从左到右书写」「从右到左书写」「语音」——
这些都是 **WebView2（Edge 内核）自带的浏览器菜单**，不是本软件的功能。
现在全局屏蔽了它。

### 3. 终端右键换成真正有用的菜单

**复制 / 粘贴 / 全选 / 清屏**。粘贴走系统剪贴板；万一被系统拒绝，会提示你用 `Ctrl+V`
（xterm 自己处理粘贴，不需要权限）。

### 4. 自动化脚本不再抢串口（重要）

上一版的开发脚本在自检时如果没指定端口，会"自动挑一个串口"去读，
自动演示还会真的打开串口终端 —— 如果那个串口正被别的程序占用（比如你的 ESP32 调试页面），
就会把人家踢下线，表现为"打开串口失败：拒绝访问"。

现在：

- **自检只有显式指定 `ZEEAI_SELFTEST_SERIAL` 才碰串口**，否则跳过；
- **自动演示不再打开串口会话**（面板里的串口列表仍会枚举，枚举是只读的）。

## 从 0.1.0 升级

应用内「设置 → 检查更新」→ 会读到本仓库的最新 Release；
或者直接下载上面的安装包覆盖安装（配置在 `%APPDATA%\ZeeAI-Terminal\`，升级不会丢）。

## 已知限制

- 仅 Windows；未做代码签名（首次运行 SmartScreen 会提示"未知发布者"）
- 远程文件暂不支持并行传输
- ADB 文件管理未在真机上验证过（开发时手头只有串口设备）
- 非 bash 的远端 shell 拿不到实时工作目录（tmux 会话不受影响）
