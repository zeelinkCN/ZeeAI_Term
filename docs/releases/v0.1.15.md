# ZeeAI Term v0.1.15

Windows 修复、macOS 首个 Universal 分发包，以及重新启用的远端 AI 状态看板。

## AI 状态：只看 ZeeAI 里打开的远端会话

- 在 ZeeAI 中打开的远端 Claude / Codex 会话可以显示到 AI 看板；Windows 和 macOS 使用相同规则。
- 普通 SSH / 可透传的 tmux 接收 OSC 7501 原生状态；herdr 窗格采用 herdr 的状态识别，成功查询间隔至少 60 秒，只显示当前已经打开的窗格。
- 需要你批准或回复的任务优先显示。完成提醒只在确认发生完成状态变化时触发，同一完成事件不会被每轮轮询重复提醒。
- 断线、关闭窗格、请求失败或状态过期不会被当成任务完成；没有可信来源时显示未知状态。
- 监控范围限于 ZeeAI 内已打开的远端会话，不扫描外部终端、本机进程或 Claude / Codex 的外部会话历史。
- herdr 观察窗口调整大小后自动恢复状态订阅；关闭控制窗口时交还控制权。连接配置或 SSH 别名发生变化时暂停观察并提示重连，避免显示另一目标的状态。

OSC 状态需要远端工具或其集成实际发送对应协议。经过 tmux 时，能否将状态传到 ZeeAI 还取决于 tmux 版本及透传配置；收不到状态时不会猜测任务已完成。普通终端的文本输出也不会被当作可靠的完成信号。

## Windows 与通用修复

- Windows 随包提供经校验的新版 Microsoft ConPTY，避免旧系统终端层过滤 AI 状态协议；增加真实 PTY 双向协议测试。独立 exe 内置同一组组件，直接替换旧目录时可自动准备，完整附上微软 MIT 许可。
- 修复管理员重启时被旧实例锁拦截、随后两个实例都退出的问题；本地终端启动失败会保留可理解的失败状态。
- Git 状态改用零字节分隔记录，正确处理中文路径、首尾空格和含 ` -> ` 的文件名，文件操作采用 literal pathspec。
- SFTP 下载验证远端文件名和本地目标，拒绝目录穿越、Windows 非法文件名及不安全的已有符号链接/目录联接目标。
- 断点续传先核对已有内容前缀，文件大小相同也验证内容，避免将不同内容拼接或错误跳过。核对已有数据会增加读取流量。
- SFTP 与 SSH 终端使用相同的 `ssh -G` 生效配置处理别名、登录用户和端口；不支持的代理组合会给出明确提示。
- 修复 herdr 上传时 OpenSSH 版本差异造成的路径问题，保留显式跳板机；密码模式通过 SFTP 上传。
- 更新检查增加超时，并按本机系统和 CPU 选择附件。独立 exe 不会被当作安装器，没有合法 SHA-256 时不会启用一键安装。
- 更新受影响的前端依赖，并增加 Windows / macOS 云端测试与打包流程。

## macOS 支持

- 支持 macOS 13.3 及以上版本；同一个 Universal DMG 同时包含 Apple Silicon 和 Intel 代码。
- 本地终端支持 zsh / bash，从用户家目录启动；界面使用 Mac 对应的快捷键、路径和入口，密码保存在 macOS 钥匙串。
- macOS 使用系统 WKWebView。Android 工具使用本机已安装的 Platform Tools，不把 Windows 的 adb.exe 或 DLL 带入 Mac 包。
- 配置保存在 `~/Library/Application Support/ZeeAI-Terminal`，应用日志位于 `~/Library/Logs/com.zeeai.terminal`。

本次 Mac 包使用 ad-hoc 签名（`APPLE_SIGNING_IDENTITY=-`），没有 Apple Developer ID 签名和 Apple 公证。首次打开从互联网下载的应用时，macOS 可能要求在「系统设置 → 隐私与安全性」中针对该应用选择「仍要打开」；这不等于应用已经通过 Apple 公证。安装时将应用拖进 Applications，升级时先退出旧版再替换，用户目录中的配置仍保留。

## 下载与升级

| 附件 | 用途 |
|---|---|
| `ZeeAI_Term_0.1.15_x64-setup.exe` | Windows 10 / 11 x64 常规安装，推荐大多数 Windows 用户使用 |
| `ZeeAI_Term_0.1.15_x64_en-US.msi` | Windows x64 MSI，适合批量部署 |
| `ZeeAI_Term-0.1.15-windows-x64-portable.zip` | Windows x64 便携包，解压即用，内含 platform-tools 与相应 DLL / 许可说明 |
| `ZeeAI_Term.exe` | Windows x64 独立主程序；替换现有目录中的 exe，ADB 等功能仍需同目录的资源文件 |
| `ZeeAI_Term_0.1.15_universal.dmg` | macOS 13.3+，兼容 Apple Silicon / Intel |
| `SHA256SUMS` | 上述五个下载文件的 SHA-256 校验清单 |

Windows 仍需要 WebView2 运行时；便携 zip 含 Android platform-tools，不包含 WebView2 离线安装包。使用便携包时保留 `resources/` 与 exe 的相对位置。

Windows 安装版可在应用内检查更新；便携版下载新 zip、退出旧版后解压替换。macOS 本版通过 DMG 手动替换应用。

两个平台共用 [GitHub 官方 Release 元数据](https://api.github.com/repos/zeelinkCN/ZeeAI_Term/releases/latest)，分别下载当前系统和架构对应的附件；不会跨平台回退。发布流程先集齐五个包，生成 `SHA256SUMS`，逐个核对 GitHub Release API 的 `asset.digest` 与大小后才发布为 latest。应用内一键更新仍以 GitHub 的 SHA-256 摘要为前提，校验清单也可用于手动核验。

## 验证范围

本地通过后端、AI 协议与状态、平台/更新选择、44 项监控界面测试和 5 项文档检查；npm 依赖审计为 0 项漏洞。原生 PTY 测试通过真实子进程验证 BEL/ST 协商、状态帧和双向回包，覆盖浏览器模拟之外的终端传输层。

发布工作流对 tag 对应的同一份源码执行版本与文档检查、前端构建、依赖审计、AI 协议与状态模型、平台和更新规则测试，以及 Windows / macOS 后端回归测试。Windows 运行完整 Edge 界面测试；macOS 运行 Chrome AI 监控专项测试。Mac 打包时校验 Universal 二进制包含两个架构，并验证 ad-hoc 代码签名。浏览器测试使用合成数据，不能代替系统 WebView2 / WKWebView 和实体设备验收。

这些检查不等于 Windows UAC、实体串口 / Android 设备、Intel Mac 真机或完整安装升级链路的验收。SFTP 仍不完整支持系统 OpenSSH 的所有认证与代理组合；远端 Claude / Codex、herdr 和 tmux 的版本差异以实际提供的状态为准。
