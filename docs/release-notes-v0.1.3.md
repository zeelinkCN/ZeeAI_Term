# ZeeAI_Term v0.1.3

这一版把「检查更新」补成了真正的一键升级：**不用再去浏览器下载、不用手动双击安装**。

## 这一版改了什么

### 1. 真·一键覆盖升级

检查到新版本后，主按钮变成 **「一键升级到 x.y.z 并重启」**：

1. 应用自己把新版安装包下到临时目录；
2. 校验通过后，用一个隐藏脚本等你退出，再静默执行安装；
3. 装完自动把新版本重新打开 —— 你只需要点一下按钮。

**两种安装版都支持，但走的路径不同**：

| 你是怎么装的 | 一键升级怎么走 | 要不要管理员 |
|---|---|---|
| **NSIS 安装包**（`..._x64-setup.exe`，装在 `%LOCALAPPDATA%\ZeeAI_Term`） | 安装包 `/S /R`：静默覆盖 + 自动重启，**全程无窗口** | 不用 |
| **MSI 安装包**（装在 `Program Files\ZeeAI_Term`） | `msiexec /i ... /qb /norestart`，装完自动重启 | **会弹一次 UAC**（MSI 本身就是全机器安装） |

**便携版**（解压在任意目录）没有"覆盖安装"这一说，按钮会变成下载 zip 手动替换 —— 配置同样不会丢。

> 注意：**要享受一键升级，需要先手动装一次 0.1.3**（或更高）。因为"会一键升级"的代码本身得先在机器上。
> 从 0.1.3 往后，之后每个版本都能一键升了。

### 2. 下载做了分片续传，网络差也能续着下

实测国内直连 GitHub 的下载 CDN 很不稳：9MB 的安装包整包传经常传着传着就被掐断，卡在几个百分点。
所以下载改成 **1MB 一段的 Range 请求**，并且：

- 断了自动重试同一段（每段最多 4 次）；
- **已下载的部分留在临时目录**，下次再点「一键升级」从断点继续，不用从头再来；
- 会自动读取 Windows「Internet 选项」里的**系统代理**（Clash / v2ray 之类），
  有代理就走代理，代理不通时后两次自动改直连；
- 下完做两重校验：大小必须和 Release 标注一致，文件头必须是 `MZ`（exe）或 `D0CF11E0`（MSI），
  对不上就当垃圾文件丢掉重下。

进度会显示在右下角那个进度面板里，跟文件传输用的是同一套。

### 3. 没有变臃肿

这一版**没有引入任何新的第三方依赖**：

- 下载用 Windows 自带的 `curl.exe`（Win10 1803+ 内置），不往程序里塞 TLS 库；
- 代理检测用系统自带的 `reg query`；
- `Cargo.lock` 与 0.1.2 完全一致。

所以主程序体积仍然是 ~15.2 MB，安装包 ~8.6 MB，和上一版一样。

| `ZeeAI_Term_0.1.3_x64_en-US.msi` | MSI 安装包（企业批量部署用；一键升级会弹一次 UAC） |

## 从旧版本升级

- 0.1.2 之前的版本：**手动装一次 0.1.3**（设置 → 检查更新 → 下载安装包），之后就能一键升级；
- 已经在 0.1.3 及以后：设置/关于里点「一键升级」即可。

配置存在 `%APPDATA%\ZeeAI-Terminal\`，升级不会丢。

## 已知限制

- 仅 Windows；未做代码签名（首次运行 SmartScreen 会提示"未知发布者"）
- 一键升级要求机器上有 `curl.exe`（Win10 1803+ 自带）；找不到时会提示改用手动下载
- 下载速度取决于你到 GitHub 的线路，线路差时会比较慢（但支持断点续传）
- 非 bash 的远端 shell 拿不到实时工作目录（tmux 会话不受影响）
