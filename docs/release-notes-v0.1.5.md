# ZeeAI_Term v0.1.5

这一版是**手感**上的改进：字号随手可调，服务器列表重新排过。

## 这一版改了什么

### 1. 字号随手调：Ctrl + 滚轮 / Ctrl + ＋－0

以前改字号得进设置拖滑块，太慢。现在：

| 操作 | 效果 |
|---|---|
| **Ctrl + 在终端里滚轮** | 上滚放大、下滚缩小 |
| **Ctrl + ＋**（或 Ctrl + `=`） | 放大一档 |
| **Ctrl + －** | 缩小一档 |
| **Ctrl + 0** | 恢复 13px |

范围 8–26px，和设置里的滑块是同一套数值，两处会同步。「视图」菜单里那三项也加上了快捷键提示。

两个实现上的取舍说一下：

- **不会每滚一格就写一次配置**：界面立刻变，写盘合并到停手后 400ms 执行一次；
- **只在终端区域生效**（侧栏、菜单上 Ctrl+滚轮 不动字号），而且缩放时**不会顺带把终端缓冲滚走**。

这几个组合键在 shell 和 tmux 里都没有含义，不影响终端输入。

### 2. 服务器列表：标题行更清楚，「默认」那行去掉了

以前是一行灰字配两个几乎看不见的 `＋` 和 `⋯`，现在：

```
服务器                    [＋ 新建]  [服务器管理]
```

- `⋯` 直接写成了 **「服务器管理」**，不用再猜；
- `＋` 变成 **「＋ 新建」**，带边框底色，鼠标移上去会亮；
- **「已保存的服务器」整块挪到了最上面**，「新建会话」按钮在它下面 —— 日常就是"选服务器 → 开会话"这个顺序。

**「默认」那一行删掉了。** 它其实是"这台服务器没填分组"，摆一行出来只会让人以为是个功能：

- 只有一个分组时**完全不显示分组标题**，就是纯服务器列表；
- 真的建了多个分组时，那个没填分组的显示成 **「未分组」**。

新建服务器对话框里的「分组」也改了说明：*可留空；留空就归到「未分组」*，并给了 `生产环境 / 测试机` 这样的例子。

### 3. 一键展开 / 折叠全部会话

服务器列表上方多了一个小按钮，跟着状态变：

```
▾ 折叠全部会话     ← 现在都开着，点了全收起
▸ 展开全部会话     ← 现在都收着，点了全展开
```

如果你手动收了其中某一台，按钮会自动变回「展开全部会话」，不会出现按钮和实际状态对不上的情况。

## 下载

| 文件 | 说明 |
|---|---|
| `ZeeAI_Term_0.1.5_x64-setup.exe` | **推荐**：NSIS 安装包，双击装 |
| `ZeeAI_Term_0.1.5_x64_en-US.msi` | MSI 安装包（企业批量部署；升级会弹一次 UAC） |
| `ZeeAI_Term-0.1.5-portable.zip` | 便携版：解压双击即用（升级需手动替换） |
| `ZeeAI_Term.exe` | 单文件免安装版 |

## 升级方式

- 已经在 **0.1.3 或 0.1.4**：设置 → 检查更新 → **一键升级到 0.1.5 并重启**；
- 还在 0.1.2 或更早：需要**手动装一次**本版（之后就能一键升了）。

配置存在 `%APPDATA%\ZeeAI-Terminal\`，升级不会丢。

## 已知限制

- 仅 Windows；未做代码签名（首次运行 SmartScreen 会提示"未知发布者"）
- 一键升级依赖系统自带的 `curl.exe`（Win10 1803+ 内置）；下载速度取决于你到 GitHub 的线路，慢的时候会分片续传
- tmux 面板用的是 tmux 2.x 以上的通用命令，没测过非常老的 tmux（1.x）
- 非 bash 的远端 shell 拿不到实时工作目录（tmux 会话不受影响）
