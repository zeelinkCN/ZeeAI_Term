# ZeeAI_Term v0.1.9

这一版的主线是 **herdr**（服务器上的 AI 终端工作区管理器）从"能用"做到"敢天天用"，
外加一批**看得见的手感修复**：启动时提示符折叠、切回标签字体花、看板把两个 codex 并成一个。

> 升级方式：安装过 0.1.8 的直接点「设置 → 检查更新 → 立即下载」即可（0.1.8 起的升级链路是好的）；
> 用便携版的解压覆盖过去就行。

---

## 1. herdr：服务器上的工作区，现在看得见、管得住

之前的 herdr 只能"进得去"，这一版把它当成一条正经的能力补齐了：

| 能力 | 说明 |
|---|---|
| 一键安装 | 在 Windows 侧下载官方二进制 + 按官方 sha256 校验 + scp 到 `~/.local/bin/herdr`；不跑远端脚本、不需要 root、已装不覆盖 |
| 两种打开方式 | **接管**（可读可写，能直接回答 AI 的选择题）和**观察**（只读，不抢窗口尺寸、不影响别的客户端） |
| 一眼看出在哪 | 侧栏会话前有绿色 `H` 标；终端上方一条状态条写着 `herdr · 接管中（可写）· w1T:p1 · 服务运行中` |
| 服务的生命周期 | AI 面板和「管理 herdr 工作区」里都能看到服务在不在跑、窗格几个，并能显式启动/停止（停止会关掉它管着的所有窗格，所以走二段确认） |
| 服务器级管理 | 右键服务器 →「管理 herdr 工作区」：逐个列出工作区（窗格、前台进程、agent 状态、在用/空壳），可接管 / 观察 / 关掉 |
| 清理空壳 | 只清理**同时满足**「不属于任何已打开/历史会话」和「每个窗格都只停着 shell」的工作区；里面正跑着 codex/vim 的一个都不碰 |
| 快捷操作栏 | 左下角可折叠的一条（和 tmux 那条同构）：新建工作区 / 左右上下分屏 / 放大还原 / 切窗格 / 重命名 / 关闭窗格 / 关闭工作区 |
| 会话行右键 | 「只从列表移除（服务器上留着）」或「在服务器上关掉这个工作区」 |

**做了什么取舍**：所有动作都是**另开一条 ssh 去跑 herdr 自己的 socket API**，
不往你的终端里模拟按键 —— 所以不抢 herdr 的快捷键，也不受"窗格里此刻在跑什么"的影响。

## 2. AI 看板：两个 codex 不再并成一个

- **合并粒度带上窗格**。以前按「环境+服务器+工具+目录」合并，于是同一台机器、同一个目录里
  开两个 codex 会并成一张卡（实测过：`w1P`、`w1Q` 两个 codex 只显示一个）。
  现在同组但不同窗格 = 两张卡；而 ps 扫描那种"说不出窗格"的卡片会被并进带窗格的那张，不会多出一张。
- **卡片 ↔ 标签对应上**：卡片第二行会写「已开在「lz · codex w1P:p1」」，已经以可写方式开着时
  按钮从「接管」变成**「切到标签」**（直接切过去，不再开第二份跟它抢输入和尺寸）。
- **默认只摆 Codex CLI / Claude Code**：没装的 Aider / Gemini CLI 不再占位；真装了才显示。
- 面板收得更干净了：「AI 命令行工具」收成右下角一个小按钮，点开才展开；
  「最近任务」默认 3 条 + 一个「展开全部」，不再让你在 260px 的小框里上下拖。

## 3. 手感修复（这几条都是你截图报过来的）

| 现象 | 根因 | 现在 |
|---|---|---|
| 启动时几个提示符"折叠"在一行 | 终端元素首帧还没布局好，就按一个很窄的宽度算出了行列数，字节按窄宽度排了一遍 | 容器小于 160×80 像素这一轮直接不 fit；列数闸门从 20×5 提到 40×12，跨重启存的尺寸也按同样门槛校验 |
| 之前那个"一条竖条宽度不对齐" | 同上：起流时用的是写死的 110×30，等前端量完再 resize，远端先把提示符按 110 列画一遍 | 开流直接用"上次量到的尺寸"（并持久化），第一台会话就是对的尺寸，不再有 resize 回灌 |
| 开个 WSL、关掉、切回 herdr 标签，字体花了（有的字没了、有的错位），缩放一下才恢复 | 终端被 `display:none` 藏起来时 WebGL 不再重绘、字形图集也可能失效；再显示出来时如果尺寸没变，原来那套"只在变了才刷"的逻辑什么都不做 | 切回来时**无条件**做一次：清字形图集 → 重新 fit → 整屏重画 |
| 用久了整机变慢（本地/远端都慢，关掉高亮也慢），重启电脑才好 | WebGL 上下文丢失后只 dispose，那条终端**永久**退回慢的 DOM 渲染 | 上下文丢失后 200ms 重建渲染器（最多 5 次），不重启也能自愈（这条是从工作空间那条线搬过来的公共修复） |
| 侧栏里同一个 herdr 窗格长出一串重复的绿色 H | 历史去重键只看 tmux 名和标题，而 herdr 会话没有 tmux 名、标题又随打开方式变 | 改成按「服务器 + 窗格」去重；读历史时顺手把老文件里已有的重复行收掉 |
| 标签名里窗格号出现两次（`… w1P:p1 w1P:p1`） | 摘名字的正则写成 `w\d+`，而 herdr 的工作区号带字母 | 正则放宽 + 显示时收掉历史里的脏数据 |
| 重新打开一个已经消失的 herdr 窗格 → 一片黑 | `terminal session control` 直接报错退出，界面没有兜底 | 打开前先探一次，窗格没了就打印人话 + 列出还在的窗格 + 退回普通 shell |
| 新建 herdr 窗格"一直卡住" | 一次性远端采集超时后没杀掉自己的 ssh，攒了 41 个孤儿把 sshd 拖垮 | 超时即杀子进程（并挂进 Job Object，App 被强杀也不留孤儿） |

## 4. 其它

- 面板上不再有"自说自话"的长句：常驻的只留状态，解释与警告放进悬停/确认里。
- 产品名保持 **ZeeAI Term**（不再出现全大写）；左下角快捷操作栏的表头也不再被强制大写
  （以前会显示成 `HERDR 快捷操作 / W9:P1`）。
- 打包脚本：便携版固定输出在 `portable/ZeeAI_Term`，打完顺手清掉 `.old-*` 备份目录，
  免得目录越堆越多、也免得点到旧版本。

## 已知限制（如实说明）

- herdr 只有 **linux-x86_64** 版本：非 Linux 服务器、或只有密码登录的服务器走不到这条路
  （不影响 tmux / 普通 shell）。
- herdr 面板里的"观感/中文输入手感"没有做过真人长测；命令链路本身是实测过的。
- AI 看板的"任务结束 → 产物清单"目前只覆盖走会话日志的那条路；shell 集成（OSC 133）还没做。
