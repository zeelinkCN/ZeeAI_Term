# ZeeAI_Term v0.1.2

这一版两件事：**「检查更新」变得真能用了**，外加**终端配色**和**自定义日志目录**两个新功能。

上一版（0.1.1）点完「检查更新」只会告诉你"发现新版本 0.1.1"，但没有地方能点着升级，
还得自己去 GitHub 找安装包 —— 那是我的疏忽。这一版补上完整闭环。

## 这一版改了什么

### 1. 检查到新版本，可以直接点着升级

**设置 → 检查更新**：如果确实有新版本，会多出三个按钮：

- **立即升级到 x.y.z** —— 用系统浏览器下载对应安装包，下完双击安装就覆盖旧版本了；
- **打开发布页** —— 想先看更新说明再下，走这里；
- **忽略此版本** —— 这个版本你暂时不想升，就不会再来烦你（换下一个版本还会提醒）。

### 2. 「关于 ZeeAI Terminal」里也能检查和升级

顶部 **帮助 → 关于 ZeeAI Terminal** 现在也带**完全一样**的检查更新区块。
两个入口共用同一套逻辑，不会再出现"一个有按钮、一个没有"的情况。

命令面板（`Ctrl+Shift+P`）里也加了一条「检查更新」。

### 3. 有更新的地方会亮小红点

后台检查到新版本时：

- 左侧边栏左下角的**设置齿轮**右上角会出现一个小红点；
- 顶部**帮助**菜单后面会出现一个小红点；
- 同时底部状态栏会提示一句（不弹窗、不打断你干活）。

### 4. 自动检查的节奏（不会烦人）

- 应用启动时，如果距离上次检查**超过 6 小时**，就静默查一次；
- 之后每 30 分钟看一次表，仍然要**间隔满 6 小时**才真的发一次请求；
- 自动检查失败（没网、GitHub 抽风）**不提示**，只有你手动点「检查更新」失败才会告诉你原因。

也就是说：一天最多查几次，且只会安静地在小红点上体现。

### 5. 顺带修掉一个隐蔽坑

如果你手动编辑过 `settings.json`，而编辑器写入了 BOM 文件头，
旧版本会解析失败并把**所有设置悄悄重置成默认值**（你会觉得"设置怎么自己变回去了"）。
现在带 BOM 也能正常读取。

### 6. 新功能：终端配色（视图 → 终端配色…）

以前终端只有一套颜色，看着满屏白字没有层次。现在内置 **15 套配色**，随点随生效
（不用重开会话，滚动历史和连接都保留）：

- **MobaXterm 经典**（黑底 16 色）/ **MobaXterm 浅色** —— 就是传统 SecureCRT / XShell 那种风格；
- **CMD 经典**（黑底银字）、**PowerShell 蓝**（经典蓝底）、**Linux 控制台**、**Ubuntu 紫**；
- **VS Code 深色 / 浅色**、**Solarized 深 / 浅**、**Monokai**、**Dracula**、**One Dark**、**Gruvbox**、**Tango 浅色**；
- **自定义** —— 背景/正文/光标/选区 + 16 个 ANSI 颜色，一共 20 个颜色随便调，
  还能直接**粘贴 Windows Terminal 的配色 JSON** 一键导入。

入口有两个：顶部 **视图 → 终端配色…**，以及 **设置 → 终端配色…**。
对话框里有实时预览（能看出提示符、`ls` 输出、error/warning 分别是什么颜色）。

> 说明：配色决定终端**怎么渲染**颜色。如果远端 shell 本身不输出颜色码，提示符还是素色的，
> 那要在服务器上开彩色（`alias ls='ls --color=auto'`，或者给 `PS1` 加颜色）。

### 7. 新功能：会话日志可以存到你自己的目录

以前日志固定写在 `%APPDATA%\ZeeAI-Terminal\logs\sessions\`。
现在 **设置 → 会话日志目录** 可以改成任意目录（比如 `D:\zeeai-logs`，或者公司的网络盘），
旁边有「选择目录…」「打开目录」「恢复默认」三个按钮，改完立即对新开的日志生效。

## 从旧版本升级

推荐路径：打开应用 → 左下角**设置** → **检查更新** → 点「立即升级到 0.1.2」→
浏览器下完双击安装，覆盖旧版本即可。配置存在 `%APPDATA%\ZeeAI-Terminal\`，升级不会丢。

也可以直接下载上面的安装包手动覆盖安装。

## 已知限制

- 仅 Windows；未做代码签名（首次运行 SmartScreen 会提示"未知发布者"）
- 远程文件暂不支持并行传输
- ADB 文件管理未在真机上验证过（开发时手头只有串口设备）
- 非 bash 的远端 shell 拿不到实时工作目录（tmux 会话不受影响）
