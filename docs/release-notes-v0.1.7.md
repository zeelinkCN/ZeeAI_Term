# ZeeAI_Term v0.1.7

这一版三块内容：**AI 任务看板**（状态 / 新消息 / 用量 / 产物）、**终端外观按类型分开配**
（配色 + 关键字高亮）、以及**会话管理的一批修复**。

---

## 1. AI 任务看板（v1）

AI Agent 面板上半部分现在是**多环境汇总卡片**，一张卡片 = 环境 + 服务器 + 项目目录 +
状态 + 耗时 + 来源：

```
● OpenAI Codex CLI        [远端]  这一轮完成
  lz · ZeeAI_term · codexAAA:0.0
  token 1.36M · 上下文 42% · 上一轮 9 秒
  正在执行：ss -tlnp
  耗时 22 分 42 秒 · tmux 窗格
```

**信号来源按可靠度分层**（越靠前越准）：

| 层 | 怎么拿到 | 特点 |
|---|---|---|
| App 自己启动的 | 点「在终端启动」时记一笔 | 开始时间、跑完没跑完都由 App 判 |
| 远端 tmux 窗格 | `tmux list-panes` + 进程树 | 能精确到**哪个会话的哪个窗格** |
| 远端 `ps` 扫描 | 一条 shell 命令 | 只能告诉你"这台机器上有" |
| 本机 PowerShell | `Get-CimInstance Win32_Process` | 全进程表扫描偏重，20 秒才一次 |

**刻意避开的坑**：`codex app-server` 这类常驻守护进程**不算任务**（之前会被误报成
"我什么时候开了这么多 codex"）；同一工具只出一张卡（父子进程、同环境+服务器+工具+目录都合并）；
WSL 的进程**进 WSL 里面查**；CMD 没有脚本钩子只显示状态；TUI 拿不到百分比，**不做进度条**；
判工具只看可执行文件名与解释器参数，**不看输出文本**。

## 2. AI 通知（分级，不再"启动就弹"）

- **启动任务不再弹通知**（以前每启动一次就打扰一次）；
- 主判据换成 **Codex 的会话日志**：`task_complete`（带 AI 最后一段话与耗时）= 有新消息，
  `*approval_request` / `request_user_input` = 在等你；**按会话去重**；
- **你在看它就不打扰**（窗口在前台 + 正打开那个会话的终端）；
- 通知分三档：**活动栏 AI 图标红点/数字**（设置里可关）→ 可选**闪 Windows 任务栏**
  → **状态栏闪烁横幅「AI 已完成，点这里切过去 ⟶」**（点一下直接切到那个会话）；
- 除当前会话（10 秒）外，**其它开着的会话每 30 秒也盯一次** —— 你人在 ADB / 本地 CMD
  里干活，照样能收到横幅。

## 3. 任务产物清单 + 预览/下载

- 任务跑完 → 用「会话工作目录 + 这一轮的起止时间」找出新增/修改的文件，
  以 **📄 按钮**列在卡片下面（实线强调边框、悬停高亮，一眼能看到）；
- **点一下就能看**：远端文件走应用内的 Markdown / HTML 预览，本地文件用资源管理器打开；
- 自动排除噪音：`.git`、`node_modules`、`.codex`、`*.sqlite*`、`*.db`；
- 预览页右上角新增 **「⬇ 下载」**：远端文件选一个本机目录就存过去（文件名不变），
  不用再跑去文件面板里找。

## 4. 终端配色与关键字高亮（按终端类型分开配）

- 「终端配色」和「关键字高亮」**合并成一个入口**：菜单 / 设置 / 命令面板里都叫
  「**终端配色与关键字高亮…**」；
- 对话框顶部先选 **作用范围**：`全局默认（所有终端）` / `远程 SSH` / `本地终端（PowerShell·CMD·WSL）` /
  `串口设备` / `Android（ADB）` —— 选定后再挑配色方案、绑高亮规则集；
- **服务器可以单独一套**：服务器编辑里有「外观跟随全局设置」开关。
  **勾着**（默认）= 跟着"远程 SSH"那一档走，以后改全局它跟着变；
  **取消勾选** = 独立一套，之后无论怎么改全局都**不会动它**；
- 高亮规则集可**新建 / 复制 / 删除 / 改名**，规则本身还是老样子（关键词、大小写、
  前景/背景色、只词 / 整行），改完**即时生效**，不用重开会话；
- 修掉一个真 bug：按终端类型设的配色**一直没生效**（存的时候用 `ssh/local` 这类键，
  取值时却用了内部类型名，键对不上就永远回退到全局）。

## 5. 设置与界面

- **设置改成二级菜单**：左边分类（外观 / 终端与会话 / 会话日志 / 通知 / 更新与关于），
  点一下右边只显示那一块；
- 设置、终端配色、新建会话、编辑服务器、新建串口连接这些**输入型对话框不再"点外面就关"**
  （填一半被手滑点掉很难受），只认右上角 **✕** 或底部按钮；
- **侧栏提示大幅精简**：14 处长句压成一行（「还没有服务器」「没有 tmux 会话」…），
  AI 面板里的解释性长句也去掉了；
- **侧栏宽度可拖**（右边缘拖动条，180–620px，记住你的宽度）；**服务器那一行**加了底色 + 左侧色条，
  和下面的会话记录明显区分；
- **标签栏**：会话标签可以**左右拖动排序**（跟着鼠标有个虚影，所见即所得，顺序会保存）；
  终端标签与文件标签用**分隔线 + 「文件」小标题 + 胶囊样式**区分开；
- 会话记录（历史行）最前面加 **`T` 小标记**表示 tmux 会话，去掉"几分钟前"，
  名字悬停可看全名。

## 6. 会话管理修复

- **普通 shell 自动编号**（`服务器 · 普通 shell 1 / 2 / 3…`），并保证不重名；
  历史记录的去重键改成「服务器 + 会话名」——
  以前所有普通 shell 共用一条记录、互相覆盖，所以"开了好几个只看到一行、数量永远不涨"；
- **标签名与左侧历史名保持一致**（以前标签会被后端标题覆盖成"配置名 · 主机"）；
- **「已打开」按名字精确匹配**：以前同一台机器上开一个普通 shell，它所有普通 shell
  的历史行都会显示"已打开"；
- 点历史行：**已打开就切过去**（普通 shell 也一样），没打开才新开；普通 shell 会用同名重开，
  不会又长出新编号；
- **删掉「把这个用户名保存到该服务器的配置里」** 那个勾选及其写回逻辑 ——
  一不小心填错会把整台服务器的登录用户改掉。现在「登录用户」只对**这次会话**生效，
  改配置请去「服务器管理」；
- **切换服务器时登录用户/tmux 名跟着换**（以前会沿用上一台的 `root`，tmux 名也就跟着错）。

## 升级方式

- 已经是 **0.1.6**：设置 → 检查更新 → **一键升级到 0.1.7 并重启**；
- 还在 0.1.5 或更早：建议**手动装一次**本版（0.1.5 的下载链路有分片续传的老问题）；
- 配置存在 `%APPDATA%\ZeeAI-Terminal\`，升级不会丢。

## 已知限制

- 仅 Windows；未做代码签名（首次运行 SmartScreen 会提示"未知发布者"）
- AI 看板目前只**读 Codex 的会话日志**（`~/.codex/sessions`）；Claude Code / Aider 等
  只有进程检测，没有"新消息 / token"这一层
- "等你批准"这一档没有真实样本可校准（本机会话策略都是 `approval_policy = never`），
  目前按事件名做了兜底匹配，精度标为"中"
- 关键字高亮：改规则**不重新着色历史输出**；不支持正则
- 一键升级依赖系统自带的 `curl.exe`；下载速度取决于你到 GitHub 的线路
