# ZeeAI_Term v0.1.11

这一版的主题是**"在 SSH 里跟 AI 说话，像用本地客户端一样"**：给远端 CLI agent 加了一个可拉出的
输入窗（多行编辑、鼠标随便改字、粘贴图片自动上传并喂给 AI），顺带修掉上一版一个会**误杀真任务**
的过滤 bug，以及若干"改了点没反应"的界面问题。

> 升级方式：安装版「设置 → 检查更新 → 立即下载」；便携版下载新 zip 解压覆盖（覆盖前先关掉窗口）。
> 这一版**仍然只允许同时跑一个实例**（便携版与安装版共用 `%APPDATA%\ZeeAI-Terminal`）。

---

## 1. 修掉 0.1.10 的一个误杀：在 VS Code 集成终端里跑 codex CLI 会被当成"桌面端"过滤掉

**怎么发现的**：在真机上翻 codex 的会话日志时，看到远端 CLI 的 rollout 里同样带着
`source="vscode"` —— 也就是说这个字段**不等于**"桌面客户端"。

**为什么必须改**：0.1.10 的本机快照过滤条件是"`originator` 含 desktop **或** `source` 含 vscode
就不读"，于是**用户在 VS Code 的集成终端里跑 codex CLI 时，他的真任务被静默过滤掉**。

**改法**：以 `originator` 为主（含 `desktop` 才拒），`source` 只在 `originator` 缺失的老日志里兜底；
并加了真机回归用例（`originator=codex-tui` + `source=vscode` 必须**保留**）。

## 2. 给远端的 AI 发消息：输入窗

在终端底部有一条**细栏**（`发给 AI · <会话名>`），点它（或 `Ctrl+Alt+A`）展开成输入窗：

- **多行编辑、鼠标随便点着改字**，`Enter` 发送、`Shift+Enter` 换行（跟 VS Code 一致）；
- **发送后焦点留在输入窗**，可以接着写下一句；想去终端自己点一下；
- 细栏**占布局空间**（不是浮在终端上）——终端自己变矮，最后一行不会被盖住。

## 3. 图片与文件：粘贴 / 拖拽 / 「＋」三条入口，一条管道

- **Ctrl+V 粘图片**（资源管理器里复制的文件、截图工具塞进剪贴板的位图都认）、**拖进窗口**、
  或者点输入窗里的「＋ 添加图片 / 文件」；
- 自动上传到远端、**把路径喂给 AI**。为什么要路径：agent 跑在服务器上，它的剪贴板不是你的剪贴板 ——
  这是位置决定的。**实测有效**：codex 会把这条路径读成真图（它的会话记录里出现
  `input_image` + base64），效果和本地客户端贴图一致；
- 附件在输入窗里显示**缩略图**（发送前确认"粘对了没有"）；发送时文字在上、路径每行一条附在末尾；
- **上传成功后清掉本地临时文件**（`%TEMP%` 不会攒垃圾）；
- 落地的远端目录可配：默认 `~/.zeeai/paste`；填 `.` = 跟随终端当前目录（对 AI 的沙箱最友好）。
  **服务器端零配置**：只用你文件面板已经在用的 SFTP，不装东西、不跑脚本、不要 root。

**一个开关说明白**：设置里那条「在终端里直接粘图片」——
**不勾（默认）**：终端里粘图片 → 放进**输入窗**（能确认、还能补一句话）；
**勾上**：走快路径，立刻把远端路径插进终端并弹几秒缩略图。**纯文本永远按焦点走**（焦点在终端就进终端）。

## 4. 三个终端交互设置（老终端用户的习惯）

| 设置 | 说明 |
|---|---|
| 粘贴用哪个键 | `Ctrl+V` / `Shift+Insert` / 两个都行（默认）。**没被选中的那个原样送给远端**：`Ctrl+V` 送 `^V`（readline 的 quoted-insert、vim 的块选择），`Shift+Insert` 送 Insert 键 |
| 终端里点右键 | 弹菜单（默认）/ 直接粘贴文本；`Shift+右键` 始终弹菜单；读剪贴板被拒会退回菜单并说明 |
| 怎么复制 | `Ctrl+Shift+C`（默认）/ `Ctrl+C` 智能（有选中就复制、没选中发 SIGINT）/ 选中即复制 |

## 5. herdr：多行消息与回车

**真机实测**（在服务器上用一个 42 字节载荷分别走两条通道）发现：

- `terminal.input` 那条**会吃掉 bracketed paste 的结尾标记**（即使窗格开了这个模式也不对称），
  而且**换行被当成逐个回车** → 一段多行提示词会被 shell 拆成几条命令执行；
- `pane send-text` 那条**逐字节透明**。

所以输入窗与粘贴改走后者；并且修掉了"**文字到了、回车没到**"的竞态（原来是 fire-and-forget +
错误被静默吞掉，回车那条 IPC 失败时界面一声不吭）。现在**顺序保证**：建通道 → 正文 → 回车；
失败一定在状态栏报出来。

## 6. 界面

- **新增「应用」一级页**：把"启动时恢复上次的会话""关闭窗口时"这类**应用级**设置从「终端与会话」搬过去；
- **设置面板排版与文案整理**：清掉 6 处直接显示给用户的**字面 markdown**（`**加粗**`、反引号）；
  正文压到一两行，理由挪进悬停提示；新增的 5 项收进「发给 AI（图片与文件）」分组；
  修掉一条排版根因 —— 提示原来是 `inline` 元素，**padding-top 根本不产生间距**，所以"提示挤在控件下面"是必然的；
- **三处写死的深色改成跟主题走**：窗口缝隙/边角（`.app` 原来不画底，一直由 `body` 的深色在画）、
  终端四周（`.pane`）、以及**没有会话时的空状态区** —— 以前切浅色主题时这些地方永远是黑的，看着像"没生效"；
- **终端配色「全局默认（所有终端）」现在真的对**所有**终端生效**：以前你在这一档改，会被"按类型"
  那层静默盖住（`termSchemeByKind`），只有选到具体那类才生效；现在在全局档改配色会**一并清掉按类型覆盖**，
  并且给"某一类终端"那档加了「**跟随全局**」——以前设了就撤不掉。

## 7. 其它修复

- **新建 tmux 会话时自己填的名字现在真的生效**（标签栏 / 侧栏 / 历史都用它；以前被后端的自动名覆盖）；
- **重命名弹窗点外面不再关闭**（也不丢输入）：只有 ✕/取消（放弃）、保存/Enter（保存）、Esc（取消）能动它；
- 修掉终端布局的一个老毛病：`.term-wrap` 里有内联 `display:block` 压过 flex，配合写死 `height:100%`
  的终端宿主，使 herdr 会话的终端**高出状态条那一条**并溢到下面的输入窗上。

## 已知限制 / 这次没做的

- **真机没验到的**：herdr 窗格里"孤立的回车"是否被原样送达（上一版的透明性实测载荷不含 `\r`）；
  真拖拽文件进窗口；右键"直接粘贴"的**成功**分支（无头环境读剪贴板会被拒，只验到"退回菜单"那条）；
  herdr 真 codex 窗格里发**多行**的实际表现。
- 图片对 agent 而言仍是"一个路径"（不是内联图片字节）——远端 CLI 就是这么吃图的；界面上给了缩略图。
- 输入窗的附件路径**不会自动清理远端**（落在 `~/.zeeai/paste`，自己看着删）；
- `Ctrl+C` 在"智能"模式下当有选中文本时会复制，这时它**不会**发给远端当 SIGINT。
